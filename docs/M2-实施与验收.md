## 方案

### 语音识别

选择 DashScope `fun-asr-realtime`，复用现有 16 kHz、单声道、20 ms PCM16LE 帧，不引入重采样。

一次按住对应一个 WebSocket 任务：

1. 通过 Authorization Bearer 鉴权，发送 `run-task`，任务为 `audio / asr / recognition`。
2. 在 `task-started` 前有界缓存音频，随后按原序发送二进制 PCM。20 ms 录音帧合并成 100 ms 网络消息，结束前刷出尾帧；缓存或发送队列超限时显式失败，不静默丢帧。
3. `result-generated` 保留一个可替换的临时句，仅当 `end_time` 非空时按 `begin_time` 提交最终句。临时 `begin_time` 变化不会堆积残片，重复最终包按同一键替换；`task-finished` 不将未完成的草稿冒充最终文本。
4. 松手后先停止并等待 AudioRecord 释放，再发送 `finish-task`。
5. `task-finished` 返回最终原文；失败、取消和超时均释放会话。

取消前可能已有语音发送到服务商。这一点已在设置页与 README 明示。

### 双向语言路由

DashScope 的识别结果未必包含可靠的语言字段，因此在最终文本上使用 **bundled ML Kit Language ID** 做本地文字语言判断；不为语言判断额外发送文本到云端。识别器能返回语言时直接采用其结果。

语言判断最多等待 1.5 秒；未知、异常或低置信度时沿用现有「译成语言 2」规则。语言栏快照固定在录音开始时，后续修改语言栏不会改变旧卡片目标。

短句、专有名词、混合语种和模型本身不支持的语种仍需人工验收。15 个翻译目标语言不等于默认 ASR 支持 15 个语种。

### 翻译

- Base URL + `/chat/completions`
- `stream: true`，`temperature: 0.2`
- system prompt 约束只输出译文、保持语气、校正合理的 ASR 错误、保留姓名数字单位，并将用户原文视为待翻译内容而非控制指令
- SSE 支持注释、CRLF、多行 data、逐事件 JSON、`[DONE]` 与 `finish_reason: stop`
- 只读取 `delta.content`，忽略角色/usage 包，不把 reasoning 内容显示为译文
- 空结果、截断、无效 JSON、provider error、长度截断均按失败处理，而非把不完整结果标为成功
- 新录音打断翻译、取消协程或 ViewModel 销毁时终止请求

自动网络重试关闭，以免重发导致重复计费。识别完成后遇到翻译错误，可对指定卡片手动重试；旧卡片也可以重试。识别阶段的临时片段不允许作为完整原文重试。

### 设置与安全

- 只使用真实服务，未配置时不发起请求
- ASR 与翻译分别保存 URL、模型与 Key；编辑草稿不通过 rememberSaveable 持久化
- URL 仅接受 WSS/HTTPS，不含用户信息、查询参数或片段
- 不跟随重定向，不记录 Authorization、音频、原文、译文或提供商错误正文
- AES-GCM 加密，随机 IV，字段名称作为 AAD，主密钥留在 Android Keystore
- DataStore 中只保存 Key 密文；读取失败不自动清空持久化设置
- 禁止应用备份，并用 Android 12+ extraction rules 排除云备份和设备迁移
- 本阶段卡片仅在内存，无录音文件、Room 历史或 TTS UI

## 本地自动化验收

命令：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

覆盖：

- DashScope 握手前排队、PCM 小端序、音频/结束消息顺序、临时结果修订与重复包、任务 ID 隔离、鉴权错误、取消及缓冲上限
- SSE 分帧、流式翻译请求与 prompt、鉴权/限流/HTTP 错误、无效/截断/空响应、消费者取消和读超时
- 未配置时不向测试服务发起请求，配置校验及 toString 密钥脱敏
- ViewModel 的正常双向路由、语言快照、误触/后台取消、录音失败、ASR 超时、无语音、60 秒限时、翻译打断、指定旧卡片重试及资源释放
- 原有状态机、语言对、音量算法回归

静态检查仍会报告已知的局部本地化、资源和依赖版本提示。`app/lint.xml` 仅将有意保留英文回退的 MissingTranslation 降为 warning，没有隐藏其他错误。
