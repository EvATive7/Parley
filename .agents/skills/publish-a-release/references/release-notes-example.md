## 한국어

### 새로운 기능

- 선택한 두 언어가 아닌 언어로 말하거나 언어를 판별할 수 없으면, 이제 두 언어로 모두 번역합니다. 대면 모드에서는 각 측에 원문과 그 측 언어로 된 번역이 표시됩니다.
- 메시지에서 인식된 원문을 고쳐 다시 번역할 수 있습니다. 세로 화면과 대면 모드 모두에서 사용할 수 있습니다.
- 서비스 설정을 파일로 내보내고 다른 기기에서 가져올 수 있습니다.
- 선택한 두 언어를 기억해 다음 실행 때도 유지합니다.

### 개선 사항

- 메시지를 누르거나 길게 누르면 세부 정보가 열리며, 가로로 긴 버튼으로 번역이나 원문을 복사하고, 편집하거나 삭제할 수 있습니다.
- 메시지 세부 정보에서 각 언어 이름을 해당 언어로 표시합니다(예: "简体中文 → 日本語").
- 대면 모드에서 최신 메시지가 각 측의 맨 아래에 표시되고, 양쪽 모두 자동으로 스크롤됩니다.
- 대면 모드에서 대화상자가 연 사람 쪽에서 밀려 나오며, 언어 목록도 짧아졌습니다.
- 대면 모드에서 인식 오류는 양쪽에, 번역 오류는 그 번역을 기다리는 쪽에만 표시됩니다.
- 설정에 정보 섹션을 추가해 개인정보 안내, 소스 코드 링크, 만든 사람, 오픈소스 라이선스를 표시합니다.

### 수정 사항

- 번역이 표시되는 중에 앱이 종료될 수 있던 문제를 수정했습니다.
- 설정에서 변경 사항을 취소하면 디버그 모드 변경도 함께 취소됩니다.

## Deutsch

### Neu

- Gesprochenes in einer anderen als den beiden gewählten Sprachen oder in einer nicht erkennbaren Sprache wird jetzt in beide übersetzt. Im Gegenüber-Modus zeigt jede Seite das Original und die Übersetzung in ihre eigene Sprache.
- Korrigiere den erkannten Text einer Nachricht und lass ihn neu übersetzen – im Hochformat und im Gegenüber-Modus.
- Exportiere die Diensteinstellungen in eine Datei und importiere sie auf einem anderen Gerät.
- Parley merkt sich die beiden gewählten Sprachen für den nächsten Start.

### Verbesserungen

- Tippe auf eine Nachricht oder halte sie gedrückt, um ihre Details zu öffnen. Dort kopieren breite Schaltflächen die Übersetzung oder das Original, bearbeiten oder löschen die Nachricht.
- Die Nachrichtendetails nennen jede Sprache in ihrer eigenen Schrift, zum Beispiel „简体中文 → 日本語“.
- Im Gegenüber-Modus erscheint die neueste Nachricht unten auf jeder Seite, und beide Seiten scrollen automatisch dorthin.
- Im Gegenüber-Modus gleiten Dialoge von der Seite der Person herein, die sie geöffnet hat, und die Sprachliste ist kürzer.
- Im Gegenüber-Modus wird ein Erkennungsfehler auf beiden Seiten angezeigt, ein Übersetzungsfehler nur auf der Seite, die auf diese Übersetzung wartet.
- Die Einstellungen haben einen neuen Bereich „Über“ mit dem Datenschutzhinweis, einem Link zum Quellcode, dem Autor und den Open-Source-Lizenzen.

### Fehlerbehebungen

- Ein Absturz, der beim Anzeigen einer Übersetzung auftreten konnte, wurde behoben.
- Beim Verwerfen von Änderungen in den Einstellungen wird jetzt auch eine Änderung am Debug-Modus verworfen.
